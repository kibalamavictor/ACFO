## 3. Donations

### 3.1 How donations will work

Because ACFO is registered in South Sudan, many international payment services are not available to it (for example, Stripe does not serve South Sudan, and Pesapal only serves organisations registered in Kenya, Uganda, Tanzania, Rwanda, Zambia, Malawi and Zimbabwe). We therefore propose two phases:

**Phase 1 — available immediately (no provider approval needed)**

- **Mobile money (MTN MoMo, m-Gurush):** the donor chooses an amount, the website shows ACFO's merchant number and a unique reference code (e.g. `ACFO-7F3K`). The donor pays from their phone and enters the transaction ID on the website.
- **Bank transfer:** the website shows ACFO's bank details with the same reference code.
- **International card / PayPal donors:** a button links to a secure external donation page that ACFO controls (see 3.5).
- ACFO staff see each pledge in the website admin, check it against the mobile money or bank statement, and mark it as received. The donor then gets a thank-you email.

**Phase 2 — once a payment provider approves ACFO**

- Mobile money payments are confirmed automatically (the donor approves a prompt on their phone and the website is told the payment succeeded). No manual checking.
- Same donor experience and admin page as Phase 1, so nothing needs to be redesigned.
